# ZLex

個人的に気になるジャンルのIME辞書<br/>
<br/>
使用しているIMEにあったファイルをダウンロードしてください。<br/>
macOSはデスクトップのみなら追加辞書、iPhoneでも使いたい場合はiCloud対応のユーザ辞書をダウンロードしてください。

### VTuber辞書
